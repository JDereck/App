Guia de Instalação

Gerenciador de Tarefas com Google Sheets — passo a passo completo

1

Criar a Planilha no Google Sheets

1
Acesse sheets.google.com (precisa de conta Google)
2
Clique no botão + para criar uma planilha em branco
3
Dê um nome para a planilha, por exemplo: Gerenciador de Tarefas
Não precisa criar colunas manualmente. O sistema cria tudo automaticamente na primeira vez.
2

Instalar o Backend (Apps Script)

1
Dentro da planilha, clique no menu Extensões → Apps Script
2
Uma nova aba vai abrir com um editor de código. Selecione todo o texto que aparece (Ctrl+A) e apague tudo
3
Abra o arquivo script.gs que está na pasta do projeto, copie todo o conteúdo (Ctrl+A → Ctrl+C) e cole no editor do Apps Script (Ctrl+V)
4
Clique no ícone de disquete ou pressione Ctrl+S para salvar. Quando pedir nome do projeto, pode colocar GerenciadorTarefas
3

Publicar como Aplicativo da Web

1
No editor do Apps Script, clique no botão azul Implantar (canto superior direito) → Nova implantação
2
Clique no ícone de engrenagem ⚙ ao lado de "Selecionar tipo" → escolha Aplicativo da Web
3
Configure assim:
• Descrição: pode deixar em branco ou escrever "versão 1"
• Executar como: Eu (seu e-mail)
• Quem tem acesso: Qualquer pessoa
4
Clique em Implantar
5
Vai aparecer uma tela pedindo autorização. Clique em Autorizar acesso, escolha sua conta Google, depois clique em Avançado → "Acessar GerenciadorTarefas (não seguro)" → Permitir
6
Copie a URL do aplicativo da Web que aparece — ela começa com https://script.google.com/macros/s/.... Guarde essa URL!
⚠ A tela de "não seguro" é normal para scripts pessoais. O Google exibe isso porque o script não passou por uma revisão oficial. Pode prosseguir com segurança — é o seu próprio script.
4

Conectar o Frontend à Planilha

1
Abra o arquivo index.html em um editor de texto (pode ser o Bloco de Notas)
2
Use Ctrl+F para buscar por: COLE_SUA_URL_AQUI
3
Substitua COLE_SUA_URL_AQUI pela URL que você copiou na Etapa 3. Mantenha as aspas!
Exemplo: var SCRIPT_URL = 'https://script.google.com/macros/s/ABC123/exec';
4
Salve o arquivo (Ctrl+S)
Agora você pode abrir o index.html direto no navegador e o sistema já funciona!
5

Colocar Online (para acessar de qualquer lugar)

Sem hospedar, o arquivo só funciona no computador onde está salvo. Para acessar no tablet ou compartilhar com a família, escolha uma opção abaixo:

Opção A — Netlify Drop Grátis Mais fácil
1
Acesse app.netlify.com/drop no navegador
2
Arraste o arquivo index.html para a área indicada
3
Pronto! O Netlify gera um link como https://nome-aleatorio.netlify.app. Esse link funciona em qualquer celular ou tablet.
Opção B — GitHub Pages Grátis Link personalizado
1
Crie uma conta em github.com se ainda não tiver
2
Crie um repositório novo e faça upload do index.html
3
Vá em Settings → Pages → Source → main → / (root) e salve. Em alguns minutos o link fica ativo.

Erros Comuns e Como Resolver

❌ "Erro ao carregar. Verifique se a URL do script está correta."

A URL no index.html está errada ou ainda como COLE_SUA_URL_AQUI. Volte na Etapa 4 e confirme que a URL foi colada corretamente com as aspas.

❌ A tarefa não aparece na planilha após criar

O script não foi reimplantado após uma alteração. Vá em Apps Script → Implantar → Gerenciar implantações → edite a implantação existente → escolha "Nova versão" e clique Implantar.

❌ Tela de autorização aparece em inglês ou pede permissão estranha

É normal. O Google exige autorização porque o script acessa sua planilha. Clique em Avançado → "Acessar [nome do projeto] (não seguro)" → Permitir. Isso só aparece uma vez.

❌ Conclusão não salva na planilha (coluna continua FALSE)

Acontece quando o script foi atualizado mas não foi reimplantado. Sempre que mudar o script.gs, precisa criar uma nova versão na implantação.

❌ No tablet aparece tela em branco ou erro de rede

O index.html foi aberto como arquivo local no tablet, não pelo link hospedado. Para funcionar em outros dispositivos, é obrigatório hospedar (Etapa 5).

❌ Campo Responsável aparece vazio no select

Nenhum membro foi cadastrado ainda. Abra a seção "Membros da Casa" no topo do sistema e adicione os nomes da família primeiro.

↻

Como Atualizar o Script (quando necessário)

Toda vez que o arquivo script.gs for alterado, é preciso criar uma nova versão na implantação. Sem isso, o servidor continua usando o código antigo.

1
No editor do Apps Script, clique em Implantar → Gerenciar implantações
2
Clique no ícone de lápis ✎ na implantação existente
3
Em "Versão", selecione "Nova versão"
4
Clique em Implantar. A URL continua a mesma — não precisa atualizar o index.html.
A URL do seu sistema não muda ao criar novas versões. Só o comportamento do servidor é atualizado.
